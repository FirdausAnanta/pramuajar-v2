# Pramuajar · Ruang Guru Interaktif (v2)

Aplikasi web interaktif pendukung guru untuk perencanaan, modul ajar, dan diferensiasi pembelajaran (Konten, Proses, Produk, dan Lingkungan Belajar).

## Fitur Utama
- **Alur Perencanaan Pembelajaran Adaptif**: Mulai dari asesmen awal, kelompok fleksibel, hingga jurnal mengajar.
- **Katalog Template Diferensiasi**: Visual 3D interaktif untuk berbagai jenis kebutuhan kelas (LKPD, RPP, Modul Ajar).
- **Asisten Guru Interaktif (Prama AI)**: Rekomendasi diferensiasi berbasis data kelas nyata.
- **Portabel & Mandiri**: Berjalan langsung di peramban tanpa ketergantungan server rumit.

## Cara Menjalankan Lokal
Cukup buka berkas `index.html` langsung di peramban web modern (Google Chrome, Safari, Firefox, Edge).
